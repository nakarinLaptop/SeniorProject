# Medical Check-up Location Prediction System 

## Feature
- doctor adding  data from medical checkup.
- doctor predict location form patient data to receive recommend location of medical check-up from model
- doctor adding medicine in prescription and print it via pdf file.

##  Technologies Used
| Layer | Technology |
|-------|-----------|
| Frontend | JSP, HTML, CSS, JavaScript |
| Backend | Python |
| Database | MySQL |
| Server | Apache Tomcat |
